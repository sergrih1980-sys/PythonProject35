# Django + DRF Courses Project

Платформа для управления курсами и уроками с авторизацией по email, ролями (пользователь / модератор), подписками на курсы, платежами и асинхронными задачами через Celery.

## Стек

- **Python 3.13**, **Django 5.2**, **Django REST Framework**
- **PostgreSQL** (для продакшена) / **SQLite** (для тестов)
- **Celery + Redis** — асинхронные задачи (рассылки, кеширование)
- **Pillow** — загрузка изображений (аватары, превью)
- **drf-yasg** — Swagger / ReDoc документация
- **pytest + pytest-django + coverage** — тестирование (покрытие 67%+)
- **Poetry** — управление зависимостями

## Функционал

- Кастомная модель пользователя: авторизация по email, поля телефон, город, аватар
- CRUD для курсов (через ViewSet)
- CRUD для уроков (через Generic-классы)
- Подписки на курсы (флаг `is_subscribed`)
- Роли: обычный пользователь и модератор (через группы Django)
- Валидация: запрещённые слова в названиях уроков/курсов
- Платежи: заглушка эндпоинта `/api/payments/create/` с валидацией суммы
- Celery-задачи: рассылка об обновлениях курса
- Swagger-документация на `/swagger/` и `/redoc/`
