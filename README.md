# Django + DRF Courses Project

Проект реализует базовый функционал для управления курсами и уроками на Django и Django REST Framework.

## Стек
- Python
- Django
- Django REST Framework
- Pillow (для работы с изображениями)

## Функционал
- Кастомная модель пользователя с авторизацией по email, полями телефон, город, аватар.
- CRUD для курсов (через ViewSet).
- CRUD для уроков (через Generic-классы).
- Загрузка изображений (превью курса, превью урока, аватар пользователя).
- Без авторизации (все эндпоинты открыты).
